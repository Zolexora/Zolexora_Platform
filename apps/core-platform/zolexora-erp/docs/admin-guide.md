# Zolexora ERP Admin Guide

## Installation

Follow the steps in `docs/installation.md` to initialize the platform.

## Configuration

- Update `.env` values before starting.
- Configure SMTP settings for email templates.
- Configure Cloudflare and Northflank secrets for production.

## Roles and Permissions

Zolexora ERP includes predefined roles for Administrator, Super Admin, Manager, HR, Accountant, Inventory Manager, Sales Executive, Purchase Executive, and Viewer.

## Backup and Restore

See `docs/backup.md` and `docs/restore.md` for backup procedures.
