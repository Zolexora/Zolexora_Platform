# Operator runbook boundary

Policy documents state required outcomes and constraints. Executable implementation performs validated behavior. Operator runbooks give tested procedures for implemented behavior. Emergency procedures add authorization, evidence, and reconciliation requirements for exceptional access.

The existing migration and disaster-recovery documents are policy-level contracts. Executable runbooks will be created only after the relevant functionality exists and is tested. No runbook may claim that an unimplemented command works, and production commands always require explicit authorization.
