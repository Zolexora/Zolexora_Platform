# Architecture Decision Records

ADRs preserve decisions that shape multiple components or constrain future implementation. Files use `NNNN-short-title.md` numbering.

Allowed statuses are **Proposed**, **Accepted**, **Superseded**, and **Rejected**. Each ADR contains Status, Context, Decision, Consequences, and Alternatives considered. Superseding an accepted decision requires a new ADR that links to the old one; accepted decisions are never silently overwritten.
