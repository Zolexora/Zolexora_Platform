# Zolexora ERP Documentation

Welcome to the Zolexora ERP documentation directory.

## 📚 Structure

- **`guides/`**: System operations, architecture, and developer guides.
  - Architecture, APIs, Developer Guidelines, User Manuals.
  - Installation, Deployment, Backup, Restore, Production Guide.
- **`reports/`**: Audit logs, certifications, and phase verification reports.
  - `certifications/`: Milestone certifications and disaster recovery validation.
  - `phases/`: Detailed implementation and remediation logs.
  - `security/`: Security reviews and raw scanner artifacts (Trivy, Gitleaks, Pip-Audit).

## 🔗 CI & Script Compatibility
Some files are symlinked at the root of `docs/` to maintain compatibility with existing CI workflows and external shell scripts that expect them at specific paths.
