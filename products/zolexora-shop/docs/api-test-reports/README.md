# API Optimization & Diagnostic Reports Directory

This directory contains active performance profiles, millisecond step-by-step traces, benchmark scorecards, and root-cause analyses for all marketplace API endpoints during optimization work.

## Reports & Inventories

- [`all-marketplace-apis.md`](./all-marketplace-apis.md) — Complete directory of all 146 API endpoints across all services, categorized by module with authentication requirements and route descriptions.
- [`auth-api-time-complexity-report.md`](./auth-api-time-complexity-report.md) — Algorithmic time and space complexity decomposition for all identity, authentication, and session security endpoints.
- [`products-api-time-complexity-report.md`](./products-api-time-complexity-report.md) — Algorithmic time and space complexity decomposition for catalog, product listings, inventory balance, and media endpoints.
- [`user-api-time-complexity-report.md`](./user-api-time-complexity-report.md) — Detailed technical audit, time/space complexity analysis, security vulnerabilities, and database optimization matrix for User category APIs.
- [`api-performance-log-findings.md`](./api-performance-log-findings.md) — Comprehensive log analysis, root causes of perceived frontend slowness, and benchmark scorecard.
