# Zolexora ERP User Guide

## Overview

Zolexora ERP is an enterprise business platform built on Frappe and ERPNext. It provides branded dashboards, financial workflows, inventory management, and operational modules.

## Getting Started

1. Open the Zolexora ERP site in your browser.
2. Use the navigation menu to access dashboards and workspaces.
3. Quick actions are available on each workspace page.

## Core Workspaces

- Dashboard
- Sales
- Purchase
- Inventory
- Accounting
- CRM
- HR
- Fleet
- Analytics
- AI
