# Secrets (Infisical)

Infisical is the only secret source. There are no `.env` or `.env.example` files and no fallback: a command run without Infisical access stops with an error.

## How it works

- Each product declares its folder in `<product>/.infisical.json`.
- Run anything that needs secrets through `bash scripts/setup/with-infisical.sh <product-dir> <command>`. Product `docker:*`, `dev:*:infisical` and `start` scripts already do this.
- Compose files list variable **names** under `environment:`; values come from the shell that `infisical run` prepared. Secrets never have defaults.
- CI and servers use a machine identity: export `INFISICAL_TOKEN`.
